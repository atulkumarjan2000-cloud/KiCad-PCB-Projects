# 12V AC to DC Converter

A custom 12V AC to DC  Converter/rectifier and filtered power supply PCB designed using KiCad.

## Project Overview

This project converts 12V AC input into filtered DC output using a full-wave bridge rectifier and smoothing capacitor.

## Main Components

- D1–D4: Bridge Rectifier
- C1: Smoothing Capacitor
- D5: Power Indicator LED
- R1/R2: Resistors
- J1: 12V AC Input
- J2: DC Output

## Tools Used

- KiCad
- Schematic Design
- PCB Design
